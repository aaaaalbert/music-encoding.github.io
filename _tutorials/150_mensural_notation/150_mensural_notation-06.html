Tempus perfectum: See Guidelines!

The encoding examples shown so far used Tempus imperfectum, i.e. a binary division of breves into semibreves. When encoding music in Tempus perfectum – signifying a ternary division instead –, the associated set of rules must be applied to correctly represent imperfected and alterated note values in MEI.

This is explained in the Mensural Notation section of the MEI Guidelines.

Short summary

On the markup side, the note's dur (duration, using mensural notation's special names for note values) is accompanied by the dur.quality attribute which encodes (im)perfection and alteration.

Furthermore, <dot>s are available in augmentation as well as division forms.

More complicated ways of imperfection can be encoded using a note's num and numbase (like tuplets in CMN MEI.)
